# NOTE: TensorFlow is NOT installed here on purpose - it is a large download and is
# only needed to TRAIN or RUN the deep-learning image models. Install it separately:
#     pip install -r ../ml/disease_detection/requirements.txt
# The backend runs perfectly without it, in clearly-labelled DEMO image mode.

# --- Trained image models -----------------------------------------------
# ONNX Runtime, not TensorFlow. Measured on this project's three models:
# TensorFlow peaks at 579 MB resident once loaded and inferring, ONNX Runtime
# at 117 MB. Every free hosting tier caps at 512 MB, so TensorFlow is killed on
# import and the app could only ever run on a laptop. The exported graphs are
# verified against the Keras originals by ml/export_onnx.py - drift under
# 5e-06 and identical predicted classes on every held-out image tested.
#
# TensorFlow is still needed to TRAIN, and to re-export. It lives in
# ml/disease_detection/requirements.txt, so the serving image does not carry
# it and the app falls back to Keras automatically if only .keras files exist.
onnxruntime==1.19.2

# --- Managed Postgres ----------------------------------------------------
# A hosted container's filesystem is wiped on every restart, so SQLite there
# loses every account and every saved analysis. With DATABASE_URL set to a
# Postgres instance the data survives; without it the app still runs on SQLite.
psycopg[binary]==3.2.3
